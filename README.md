# 豆包无水印下载器

独立的 Windows 桌面工具。打开豆包并登录后，正常生成视频；工具会监听当前页面结果，解析无水印资源并自动保存到本机。

它不依赖短剧工作台、项目文件、镜头表或提示词流程。

## 下载

前往 [Releases](https://github.com/ggoukebo/doubao-video-auto-downloader/releases/latest) 下载 Windows x64 便携版。下载后直接运行，无需安装。

## 使用

1. 启动 `豆包无水印下载器`。
2. 点击「打开豆包」，首次使用时在豆包窗口登录。
3. 在豆包中正常生成视频。
4. 生成完成后，工具自动下载并显示在下载记录中。
5. 使用「播放」或「定位」查看文件；保存目录可在主界面更改。

默认保存目录：系统「视频/豆包无水印视频」。

## 工作方式

- Electron 主进程监听豆包 `/im/chain/single` 响应。
- 从响应中提取 `fallback_api`，改写为无水印参数后请求媒体元数据。
- 解析普通地址、Base64 地址和 qAAB 加密地址。
- 使用登录会话下载 MP4，先写临时文件，成功后再原子重命名。
- 页面 Hook 作为备用捕获路径，原生调试器捕获失败时仍可工作。

## 开发与构建

```powershell
npm install
npm start
npm run dist:win
```

便携版输出到 `release/豆包无水印下载器-1.0.0-便携版.exe`。
